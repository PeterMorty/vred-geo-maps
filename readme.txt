VRED Geo Maps manages reusable locations and displays them on Leaflet maps via shortcode.

== Description ==

VRED Geo Maps provides reusable locations, optional location types, marker inheritance, clustering, filters, lists, responsive layouts and shortcode output.

== Installation ==

1. Upload and activate VRED Geo Maps.
2. Open Settings > VRED Geo Maps.
3. Add locations and optional location types.
4. Insert `[vred_geo_map]` wherever WordPress processes shortcodes.
